## 🚀 Featured Project

### 🚨 AI-Powered Emergency Voice Intelligence & Risk Alert System

> An AI system that detects voice distress and fires emergency alerts — no phone unlock, no button press required.

When I moved to an unfamiliar city alone, I realised there were moments where I wouldn't be able to reach my phone in an emergency. That idea became this project.

**How it works:**
- User sets a secret custom trigger phrase
- System analyses voice pitch, speed & tremor via OpenAI Whisper
- Claude AI classifies context and generates a risk score (0–100)
- If score > 80 → Telegram alert fires to all emergency contacts in < 3 seconds

| Layer | Tech |
|---|---|
| Backend | Python 3.12 + Django REST Framework |
| Database | Supabase PostgreSQL + Row-Level Security |
| Voice | OpenAI Whisper API |
| AI Engine | Anthropic Claude 3 Haiku |
| Alerts | Telegram Bot API |
| Deployed | Render |
